---
name: Persetujuan perubahan kode
description: Instruksi pengguna untuk meminta persetujuan sebelum mengubah kode aplikasi.
---

Jangan merubah code apapun tanpa persetujuan pengguna.

**Why:** Pengguna meminta aturan ini secara eksplisit.

**How to apply:** Pelajari kode secara baca-saja. Sebelum mengubah kode, jelaskan bagian yang akan diubah dan dampaknya, lalu minta persetujuan pengguna. Permintaan untuk mempelajari atau menjelaskan aplikasi bukan persetujuan untuk mengubah kode.
