---
name: Persetujuan perubahan kode
description: Instruksi pengguna untuk meminta persetujuan sebelum mengubah kode aplikasi.
---

Jangan merubah code apapun tanpa persetujuan pengguna.

Semua logika aplikasi sudah sesuai di lapangan; jangan ada yang diubah.

Pengguna menjalankan aplikasi di server STB dan aplikasi sedang digunakan kasir untuk transaksi.

**Why:** Pengguna meminta aturan ini secara eksplisit.

**How to apply:** Pelajari kode secara baca-saja. Bedakan perbaikan teknis dari perubahan aturan bisnis; pertahankan aturan bisnis yang sudah sesuai di lapangan. Sebelum mengubah kode, jelaskan bagian yang akan diubah dan dampaknya, lalu minta persetujuan pengguna. Permintaan untuk mempelajari atau menjelaskan aplikasi bukan persetujuan untuk mengubah kode. Jangan menyamakan database pengembangan Replit dengan data server STB; koordinasikan setiap tindakan yang dapat mengganggu transaksi aktif terlebih dahulu.
