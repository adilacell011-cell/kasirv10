---
name: Rekap permanen untuk owner
description: Kebutuhan pengguna agar pendapatan dan bonus tetap tersedia setelah rincian transaksi lama dihapus dan pembacaan dashboard ringan.
---

Pengguna menginginkan transaksi yang sudah selesai menjadi rekap tersimpan agar pembacaan dashboard owner ringan dan tidak membebani server atau RAM. Pendapatan dan bonus harus tetap tersedia walaupun rincian transaksi lama dihapus.

Sebagai owner, pengguna tidak membutuhkan rincian penjualan tiap cabang; yang diperlukan adalah catatan total penghasilan per shift per cabang.

**Why:** Pengguna menyatakan kebutuhan ini saat membahas penggunaan RAM API pada server STB.

**How to apply:** Bedakan rekap pendapatan dari saldo bonus yang mengikuti status komisi. Rekap tidak boleh bergantung pada keberadaan rincian transaksi lama. Kebutuhan ini bukan persetujuan untuk mengubah kode atau menghapus data; aturan persetujuan perubahan tetap berlaku.
